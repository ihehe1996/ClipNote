# ClipNote

Windows 上的剪贴板历史工具。按 `Alt+Q` 唤出面板。

## 功能

- 收集复制过的**文本和图片**，最新的排在最前，重复的不存两份，上限 200 条
- 点一条即粘贴到光标处，面板不关，可以连着点好几条；列表顺序不会被打乱
- **收藏**：点每条右边的星星收起来，顶部「收藏」选项卡里能单独看
- 鼠标停在文字条目上显示完整内容，停在图片缩略图上显示大图
- 右键条目可以收藏、删除；右键空白处可以清空历史或取消全部收藏
- 拖面板的边或角就能改大小，尺寸和位置都会记住
- 历史会存下来，关掉程序再开还在，图片也一样
- 有新版本时自己更新

## 用法

1. 在任意程序里正常 `Ctrl+C` 复制
2. 按 `Alt+Q` 唤出面板（程序刚启动时面板就是开着的）
3. **单击**要粘的那一条

收起面板：再按一次 `Alt+Q`、点标题栏右边的 ✕，或者托盘右键菜单。退出走托盘菜单。

面板只能鼠标点选，用不了键盘。粘进以管理员权限运行的程序时，需要你自己按一下 `Ctrl+V`。

## 更新

有新版本时程序自己会更新，不用管。想手动查就走托盘菜单或标题栏齿轮里的「检查更新…」。

## 下载

[Releases](https://github.com/ihehe1996/ClipNote/releases) 页面里：

- `ClipNote-v<版本>-install.exe` —— 装到 `Program Files`，有开始菜单项和卸载项
- `ClipNote-v<版本>.zip` —— 解压到哪就在哪跑，不写注册表、不留痕

两个都能自动更新。
