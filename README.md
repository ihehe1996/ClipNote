# ClipNote

Windows 上的剪贴板历史工具。你复制过的东西都在后台收着，按 `Alt+Q` 唤出面板，
点一条就粘回你原来那个窗口。

面板**不抢焦点**（和系统自带的 Win+V 一个路子）：唤出时你正在打字的程序连光标都不闪。

## 功能

- 收集复制过的**文本和图片**，最新的排在最前，重复的不存两份，上限 200 条
- 点一条即粘回原来那个窗口，面板不关，可以连着点好几条；列表顺序不会被打乱
- 右键条目删除单条，右键空白处清空全部
- 拖面板的边或角就能改大小，尺寸会记住，下次启动还是这么大
- 从 GitHub Releases 检查更新，有新版本自己换掉自己

> 历史只在内存里，退出就没了。文件类剪贴板、钉住、落盘持久化还没做。

## 用法

1. 在任意程序里正常 `Ctrl+C` 复制
2. 按 `Alt+Q` 唤出面板（程序刚启动时面板就是开着的）
3. **单击**要粘的那一条

收起面板：再按一次 `Alt+Q`、点标题栏右边的 ✕，或者托盘右键菜单。退出走托盘菜单。

面板收不到键盘输入，所以没有搜索框、不能用方向键，只能鼠标点选 —— 这是「不抢焦点」的代价。
目标程序**以管理员权限运行**时粘不进去，这时内容已经写进剪贴板了，自己按 `Ctrl+V` 就行。

## 更新

启动时会自动查一次有没有新版本（有节流，不是每次都去查 GitHub）。查到会弹一个托盘气泡，
点它就能打开更新窗口。也可以自己在托盘右键菜单或标题栏的齿轮菜单里点「检查更新…」随时查。

点「下载并更新」之后：下载新版本 → 校验 → ClipNote 自己关掉，换好文件再自己启动起来。
如果程序装在一个写不进去的目录里，它会提示你走「打开下载页」手动换。

> 更新会让程序重启一次。剪贴板历史存在内存里，所以更新完历史是空的。

## 下载

[Releases](https://github.com/ihehe1996/ClipNote/releases) 页面里：

- `ClipNote-v<版本>-install.exe` —— 安装版，装到 `Program Files`，有开始菜单项和卸载项
- `ClipNote-v<版本>.zip` —— 解压到哪就在哪跑，不写注册表、不留痕

两个都支持自动更新。安装版装的时候会弹一次 UAC，之后 ClipNote 换自己的文件就不用再弹了。

> 程序没有代码签名，双击时 Windows 会先弹一句「Windows 已保护你的电脑」，
> 点「更多信息 → 仍要运行」即可。
